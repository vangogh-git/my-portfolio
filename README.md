# Vani’s Portfolio

### 🌐 [Visit the live website → vangogh-git.github.io/my-portfolio](https://vangogh-git.github.io/my-portfolio/)

Hi, I am Vani. This is my personal portfolio website, where you can see my work, learn about me and get in touch.

The homepage has a video of a little doll that follows your mouse: move your cursor left and right and the video scrubs along with it.

## Built with

- React and TypeScript
- Vite
- Tailwind CSS
- GitHub Pages and GitHub Actions for hosting and deployment

## Run it locally

```bash
git clone https://github.com/vangogh-git/my-portfolio.git
cd my-portfolio
npm install --legacy-peer-deps
npm run dev
```

Then open http://localhost:3000 in your browser.
